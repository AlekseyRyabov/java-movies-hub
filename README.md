# 🎬 Movies API

REST API для управления каталогом фильмов. Позволяет получать список фильмов, фильтровать их по году выпуска, добавлять новые записи с валидацией данных, а также просматривать и удалять фильмы по идентификатору.

## 📌 Обзор эндпоинтов

| Метод | Эндпоинт | Описание |
| :--- | :--- | :--- |
| `GET` | `/movies` | Получить список всех фильмов |
| `GET` | `/movies?year={YYYY}` | Отфильтровать фильмы по году выпуска |
| `POST` | `/movies` | Добавить новый фильм |
| `GET` | `/movies/{id}` | Получить фильм по его ID |
| `DELETE` | `/movies/{id}` | Удалить фильм по его ID |

---

## 📦 Модель данных

Объект фильма (`Movie`) в ответах API имеет следующую структуру:

```json
{
  "id": "d88c61d0-cbfe-4a82-a506-b5cfd7d7f3c8",
  "title": "Начало",
  "year": 2010
}
```

| Поле | Тип       | Описание |
| :--- |:----------| :--- |
| `id` | `uuid`    | Уникальный идентификатор фильма (генерируется автоматически) |
| `title` | `string`  | Название фильма (от 1 до 100 символов) |
| `year` | `integer` | Год выпуска фильма (от `1888` до `текущий год + 1`) |

## 🚀 Описание эндпоинтов

### 1. Получение списка фильмов

Возвращает все фильмы из базы данных. Поддерживает опциональную фильтрацию по году выпуска.

* **URL:** `/movies`
* **Метод:** `GET`
* **Query-параметры (опционально):**
    * `year` (`integer`) — год выпуска фильма (формат `YYYY`).

#### Примеры запросов

```http
GET /movies
GET /movies?year=2010
```

#### Возможные ответы

* **`200 OK`** — Успешный запрос. Возвращает массив фильмов (или пустой массив `[]`, если фильмов нет).
  ```json
  [
    {
      "id": "d88c61d0-cbfe-4a82-a506-b5cfd7d7f3c8",
      "title": "Начало",
      "year": 2010
    },
    {
      "id": "d88c61d0-cbfe-4a82-a506-b5cfd7d7f3c9",
      "title": "Интерстеллар",
      "year": 2014
    }
  ]
  ```

* **`400 Bad Request`** — Указан некорректный параметр запроса `year` (например, не число или пустое значение).
  ```json
  {
    "error": "Некорректный параметр запроса — 'year'"
  }
  ```

---

### 2. Добавление фильма

Создает новую запись о фильме в каталоге.

* **URL:** `/movies`
* **Метод:** `POST`
* **Заголовки:** `Content-Type: application/json`

#### Тело запроса

| Поле | Тип | Обязательное | Правила валидации |
| :--- | :--- | :---: | :--- |
| `title` | `string` | Да | Непустая строка, длина **≤ 100** символов |
| `year` | `integer` | Да | Число от **1888** до **текущий год + 1** |

```json
{
  "title": "Матрица",
  "year": 1999
}
```

#### Возможные ответы

* **`201 Created`** — Фильм успешно добавлен. Возвращает созданный объект с присвоенным `id`.
  ```json
  {
    "id": "d88c61d0-cbfe-4a82-a506-b5cfd7d7f3c8",
    "title": "Матрица",
    "year": 1999
  }
  ```

* **`415 Unsupported Media Type`** — Передан неверный заголовок `Content-Type` (ожидается `application/json`).

* **`422 Unprocessable Entity`** — Ошибка валидации полей запроса.
  ```json
  {
    "error": "Ошибка валидации",
    "details": [
      "название не должно быть пустым",
      "год должен быть между 1888 и 2027"
    ]
  }
  ```

---

### 3. Получение фильма по ID

Возвращает подробную информацию о конкретном фильме по его идентификатору.

* **URL:** `/movies/{id}`
* **Метод:** `GET`
* **Path-параметры:**
    * `id` (`string`) — идентификатор фильма.

#### Пример запроса

```http
GET /movies/d88c61d0-cbfe-4a82-a506-b5cfd7d7f3c8
```

#### Возможные ответы

* **`200 OK`** — Фильм найден.
  ```json
  {
    "id": "d88c61d0-cbfe-4a82-a506-b5cfd7d7f3c8",
    "title": "Начало",
    "year": 2010
  }
  ```

* **`400 Bad Request`** — Переданный `id` не является uuid.
  ```json
  {
    "error": "Некорректный ID"
  }
  ```

* **`404 Not Found`** — Фильм с указанным `id` не найден.
  ```json
  {
    "error": "Фильм не найден"
  }
  ```

---

### 4. Удаление фильма

Удаляет фильм из каталога по его идентификатору.

* **URL:** `/movies/{id}`
* **Метод:** `DELETE`
* **Path-параметры:**
    * `id` (`string`) — идентификатор фильма.

#### Пример запроса

```http
DELETE /movies/d88c61d0-cbfe-4a82-a506-b5cfd7d7f3c8
```

#### Возможные ответы

* **`204 No Content`** — Фильм успешно удален (тело ответа отсутствует).
* **`404 Not Found`** — Фильм с указанным `id` не найден.
  ```json
  {
    "error": "Фильм не найден"
  }
  ```

## 🚦 Коды ответов HTTP

| Код статуса                  | Значение               | Когда возвращается                                          |
|:-----------------------------|:-----------------------|:------------------------------------------------------------|
| `200 OK`                     | Успешно                | Успешное получение списка фильмов или одного фильма         |
| `201 Created`                | Создано                | Новый фильм успешно добавлен                                |
| `204 No Content`             | Нет содержимого        | Фильм успешно удален                                        |
| `400 Bad Request`            | Некорректный запрос    | Невалидный `id` в пути или параметр `year` в строке запроса |
| `404 Not Found`              | Не найдено             | Запрашиваемый или удаляемый фильм отсутствует               |
| `405 Method Not Allowed`     | Неподдерживаемый метод | Метод не поддерживается                                     |
| `415 Unsupported Media Type` | Неподдерживаемый тип   | Заголовок `Content-Type` не равен `application/json`        |
| `422 Unprocessable Entity`   | Ошибка валидации       | Переданы некорректные значения                              |
